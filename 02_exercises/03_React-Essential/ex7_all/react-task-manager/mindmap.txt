--------------------------------------------------
| Component | Type              | Responsibility |
| --------- | ----------------- | -------------- |
| App       | Smart / Container | State + logic  |
| TaskForm  | Controlled        | Input + events |
| TaskList  | Presentational    | Render list    |
| TaskItem  | Dumb / Leaf       | Display only   |
--------------------------------------------------
| State  | Lives In | Why                       |
| ------ | -------- | ------------------------- |
| tasks  | App.jsx  | Shared by many components |
| filter | App.jsx  | Controls list view        |
| title  | TaskForm | Local form data           |
| status | TaskForm | Local form data           |
--------------------------------------------------
🧠 GOLDEN REACT RULES (FROM YOUR PROJECT)
1. State lives high, UI lives low
2. Props go down, events go up
3. Never duplicate state
4. Components do one job
5. JSX describes UI, not logic

🧠 WHAT useRef IS (MENTAL MODEL)
useState

   “When this changes → re-render UI”

useRef

   “I need to remember something without re-rendering”

Typical uses:
   - DOM access (focus, scroll)
   - Storing timers / previous values
   - Imperative actions

❌ WHAT useRef IS NOT
   ❌ NOT for UI data
   ❌ NOT for rendering
   ❌ NOT for replacing state
